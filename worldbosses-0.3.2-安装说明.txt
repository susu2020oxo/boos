万物皆 Boss v0.3.2
Minecraft Java 1.21.10 · Fabric Loader 0.17.3 或更新版本 · Java 21

本次修改：
生存模式下，全部8种模组食物每次食用消耗1份，包括6种专属食物、凝血腐肉和净化肉羹。
最后1份吃完后消失，不再恢复数量。强化效果保留。
创造模式沿用原版规则；武器、工具和装备的免使用消耗、无技能冷却设置保持不变。
保留0.3.1的青蛙、恼鬼、悦灵模型修复及原有其他内容。

安装：
1. 退出游戏，移出mods文件夹里的旧World Bosses JAR。
2. 将本版JAR放入mods，并保留对应Minecraft 1.21.10的Fabric API。
3. 安装ZIP内的mods目录已包含模组与Fabric API；已有API时只保留一份。
4. 重启游戏即可，无需新建存档。多人游戏客户端与服务器使用对应版本。

验证：构建、6项生成预算测试、5项资源测试、20项模组GameTest、正式JAR结构检查通过。
本次未重新进行图形客户端实拍；此次改动仅涉及食物消耗及对应文字说明。
