万物皆 Boss 0.3.3
Minecraft Java 1.21.10 · Fabric · Java 21

安装：
1. 在启动器选择 Minecraft 1.21.10 的 Fabric 配置，Fabric Loader 0.17.3 或更新版本。
2. 把安装包 mods 文件夹里的两个 JAR 放进该游戏实例的 mods 文件夹。
3. 若已有 Fabric API，保留对应版本的一份即可。更新时移出旧的 World Bosses JAR。
4. 客户端和多人服务器均需安装。启动游戏。

此包包含模组和 Fabric API；不包含 Minecraft 本体或启动器。

本版：
0.3.3：全部68种Boss的生命值为0.3.2版的6倍，近战、远程、爆炸与技能命中伤害为3倍。
猪/牛96 HP，羊72 HP，鸡48 HP，僵尸300 HP，铁傀儡720 HP，监守者3000 HP。
旧存档自动升级并保留受伤比例，反复加载不会叠加或补满血；无需新建存档或删除配置。
友好生物保留原版行为；玩家、水生排除物种和召唤/分裂随从不套用倍率。
无攻击者归属的毒、凋零和燃烧持续伤害沿用原版。爆炸方块破坏强度仍为200。
0.3.2：全部8种模组食物在生存模式下每次食用消耗1份，强化效果保留。
0.3.1修复青蛙、恼鬼与悦灵模型不可见，纠正实际渲染节点、高度与动画绑定。
监守者比0.2版大5倍；铁傀儡、马、野猪、蜘蛛和洞穴蜘蛛重做。
苦力怕/裂核弹爆炸强度200，会摧毁方块；技能免消耗、无冷却，装备属性加强。
68 种非水生 Boss 的新身体模型、独立材质和发光层。
68 件专属成品：21 武器、25 工具、6 增益食物、16 装备，各有独立作用与三维物品模型。
68 种立体刷怪蛋。创造模式按四个中文分类查看物品；操作说明在物品悬浮提示中。
猪额外掉落 72–96 个猪排，着火时为熟猪排；还掉专属增益肉排。
每位玩家周围 128 格，相交区域合并；每战斗家族自然生成上限 4 只、总量默认 12 只。
配置文件：config/worldbosses.json。
旧材料保留用于旧存档兼容，可用三份旧材料回收对应新成品。

技能仍有共享招式框架；未完成所有生物的复杂阶段连招。
已通过构建、6 项生成预算单元测试、5 项资源测试、26 项模组 GameTest 及正式 JAR 结构检查。
本次数值修改未重新进行图形客户端验证。
细节、逐种掉落说明和检查范围见 README.md 与 专属掉落图鉴.md。
